About the Project

**Book A Metro Ticket** is a ServiceNow application designed to simplify
the process of booking metro tickets through the Service Catalog.

The application allows users to select their starting and destination
stations, choose the journey type and number of passengers, automatically
calculate the fare, select a payment method, and generate a QR code for
the ticket.

---

## ✨ Key Features

- 🚉 Metro station selection
- 🎫 Metro ticket booking
- 💰 Automatic fare calculation
- 👥 Passenger selection
- 💳 Multiple payment modes
- 🔄 Conditional payment field using UI Policy
- 📱 QR code ticket generation
- ⚙️ ServiceNow automation

---
